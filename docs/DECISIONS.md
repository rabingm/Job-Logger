# M0 decisions

Date: 23 October 2026 (Australia/Perth)

- Audience remains general working professionals. Resume App is a working name. No editor screenshot was supplied, so the Clean template is an original restrained green/cream layout based on the textual brief.
- pnpm workspace with hoisted node modules; no Turborepo needed for three packages. Node 24.22.1 / pnpm 11.25.0 were available through Codex’s bundled runtime. Registry-confirmed Expo template versions selected: Expo 58.0.17, Router 58.0.25, React 19.3.0, React Native 0.88.0; Next.js 16.4.2. pnpm-lock.yaml captures the resolved graph. Expo’s installed compatibility map verified native dependencies. [Expo project guidance](https://docs.expo.dev/get-started/create-a-project/) and [Next installation](https://nextjs.org/docs/app/getting-started/installation) were consulted.
- A single Expo route holds the M0 workspace. The visible Log / My résumés / Profile navigation uses native React Native components. Editor and preview are local view states; deep links and screen splitting can follow usability review.
- All state crosses a validated shared schema. The replaceable local repository serializes writes through an asynchronous storage port. It is deliberately scoped to a fictional local workspace, not an authentication substitute.
- Version role selections are ordered `{id, visible}` arrays. Skills and education currently have section visibility only; profile entries are ordered lines. Per-entry version selection/order for those sections is deferred to M2. New roles enter existing versions hidden. Adding an achievement explicitly shows its role. New achievements never automatically enter a version.
- Achievement order is global in storage and grouped by role when rendered; controls explain that role order is separate. No drag gesture is needed for M0; accessible up/down buttons are implemented.
- A null text override follows original wording; an empty override remains empty. Archiving removes a bank entry from suggestions, while existing version selections continue resolving it.
- Share preview resolves the current draft live and explicitly says it is unpublished. Pure immutable snapshot/access functions are tested for future reuse, but there is no publication adapter, public link or analytics UI. The Next.js `/demo` route is a fixed fictional fixture, not a way to publish local edits.
- Onboarding offers the labelled fictional example or an empty workspace. The latter can capture achievements without roles and fill optional profile fields later. Guided three-achievement onboarding is deferred.
- Contact is omitted from the resolved payload when hidden. The Next server response check verifies it is absent from HTML and serialized page data. This does not claim backend authorization or production revocation guarantees.
- pnpm automatic dependency reinstallation before scripts is disabled (`verifyDepsBeforeRun: false`); installation is an explicit setup step. esbuild's package build script is allowed; sharp's optional install script is not needed for this asset-free app. Tests use Node’s test runner with tsx as an import hook, avoiding tsx CLI IPC requirements in restricted environments.
- No cloud resources, external accounts, AI calls, analytics, publication or deployments were created. No system Xcode installation or global Node installation was attempted.
